# SmartRent Android

학교 기자재를 앱에서 조회·예약하고, QR/바코드 스캔과 AI 추천으로 대여·반납하는 기자재 대여 서비스 SmartRent의 Android 앱입니다.

백엔드 저장소: [SmartRent-BE](https://github.com/Hansung-SmartRent/SmartRent-BE)

## 주요 기능

- **학교 계정 인증**: 한성대 이메일 가입·로그인, 메일 인증번호, 학번·학생증 제출 후 관리자 승인
- **기자재 조회·예약**: 카테고리 목록·검색·상세, 날짜·시간 칸 예약, 예약 취소
- **장기 대여**: 노트북 등 6개월 단위 장기 대여, 일반 대여와 카테고리 분리
- **스캔**: QR과 바코드 인식. 학생은 기자재 찾기, 수령·반납 스캔은 관리자만
- **수령·반납**: 관리자가 기기 코드를 스캔해 대여 시작·반납 처리, 학생은 앱에서 반납 신청
- **연장**: 일반 대여 한 번 연장, 다음 예약·운영 시간 기준으로 가능 여부 표시
- **경고·정지**: 노쇼·연체·파손 경고, 3회 시 6개월 정지, 마이페이지에서 내역 확인
- **푸시 알림**: 반납 하루 전, 반납 15분 전, 즉시 반납 요망, 예약 취소, 노쇼
- **AI 기자재 추천**: 사용 목적 입력 후 품목·추천 이유 표시
- **관리자**: 학생증 승인/반려, 전체 기자재 한 화면 관리, 목록 자동 새로고침

### 학생 앱

| 기능 | 내용 |
|---|---|
| 초기 세팅 | Expo 프로젝트, 네비게이션, API 클라이언트, 토큰 저장 |
| 인증 | 학교 이메일 가입·로그인, 6자리 인증번호, 이름·학번·학생증 제출, 승인 대기·반려 사유 |
| 기자재 | 카테고리 목록, 이름 검색, 상세(제조사·구입 연도·활용 방안·대여 장소·가능 대수) |
| 예약 | 날짜·시간 칸 선택, 전체선택, 예약 실패 에러 코드 표시, 예약 취소 |
| 장기 대여 | 시작일 선택, 6개월 반납일 자동 표시, 연장 안내 문구 |
| 스캔 | QR/바코드·사진 인식으로 기자재 찾기 (수령·반납 처리 아님) |
| AI 추천 | 사용 목적 200자 입력, 하루 10회, 품목·추천 이유만 표시 |
| 반납·연장 | 반납 신청, 일반 대여 1회 연장, 상태(대여 중·즉시 반납 요망) 표시 |
| 마이페이지 | 예약·대여 내역, 이메일·비밀번호 변경, 경고 날짜·사유·정지 해제일 |
| 알림 | 반납 전 알림 on/off, 예약 취소·즉시 반납 요망·노쇼는 끌 수 없음 |

### 관리자 앱

| 기능 | 내용 |
|---|---|
| 학생증 승인 | 제출 사진 확인, 승인/반려, 반려 사유 입력. 처리 후 사진은 서버에서 삭제 |
| 수령 | 예약 선택 → 기기 코드 스캔 → 모델·상태 검증 → 대여 시작 |
| 반납 | 학생 신청 승인 또는 기기 스캔으로 바로 처리. 정상/파손 선택 후 승인 |
| 기자재 관리 | 전체 기자재를 한 화면에서 조회, 몇 초마다 자동 새로고침 |
| 상태 수정 | 대여 상태 수정 시 실제 시각 입력, 수정 기록 확인 |
| 경고 | 경고 취소, 노쇼를 대여 중으로 정정 |

### 공동

- 백엔드 API 명세를 기준으로 화면·요청/응답 타입 맞춤
- 학생/관리자 권한에 따라 진입 화면 분기
- 푸시 알림 수신(FCM)은 백엔드 발송 스펙에 맞춤

이번 범위에서 빼는 화면(여유가 있을 때 추가):

- 공지사항, 대여 통계, 문의사항(화면만 두고 준비 중 안내)
- 알림 끄기 상세 설정, 기자재 모델 등록·수정, 관리자의 학생 이름·학번 수정

## 프로젝트 구조

현재는 Expo blank(TypeScript) 템플릿 상태입니다. 아래는 화면 구현 시 맞출 구조입니다.

```
app/
├── (auth)/                 # 로그인, 가입, 메일 인증, 학생증, 승인 대기
├── (student)/              # 학생 앱
│   ├── index.tsx           # 기자재 목록
│   ├── equipment/[id].tsx  # 상세
│   ├── reserve/[id].tsx    # 예약
│   ├── long-term/[id].tsx  # 장기 대여
│   ├── scan.tsx            # 기자재 찾기 스캔
│   ├── recommend.tsx       # AI 추천
│   ├── rentals.tsx         # 내 대여
│   └── mypage.tsx
└── (admin)/                # 관리자 앱
    ├── index.tsx           # 전체 기자재 (자동 새로고침)
    ├── pickup.tsx          # 수령 스캔
    ├── return.tsx          # 반납 스캔
    └── approvals.tsx       # 학생증 승인
src/
├── api/                    # axios 인스턴스, 도메인별 API
├── components/
├── hooks/
└── types/                  # 백엔드 응답 타입
```

## 시작 가이드

필요한 환경:

| 구분 | 내용 |
|---|---|
| Node.js | LTS (개발 환경 기준 v24) |
| npm | Node와 함께 설치 |
| Android Studio | SDK, 에뮬레이터 또는 실기기 |
| ANDROID_HOME | SDK 경로. 프로젝트 폴더와 달라도 됨 (기본: `%LOCALAPPDATA%\Android\Sdk`) |

필요한 환경변수:

| 키 | 설명 |
|---|---|
| EXPO_PUBLIC_API_BASE_URL | 백엔드 API 주소 (예: `http://localhost:8080/api/v1`) |

로컬에서 백엔드를 쓰면 에뮬레이터는 `http://10.0.2.2:8080/api/v1`, 실기기는 같은 Wi-Fi의 PC IP를 사용합니다.

설치 및 실행:

```
git clone (저장소 주소)
cd smartrent-android
npm install
npx expo start
```

터미널에서 `a`를 누르면 Android로 실행됩니다.

- 에뮬레이터: Android Studio Device Manager에서 가상 기기 실행 후 연결
- 실기기: USB 디버깅 켜고 `adb devices`에 기기가 보여야 함

스크립트:

```
npm start          # Expo 개발 서버
npm run android    # Android로 실행
```

## 공통 응답 / 에러 포맷

백엔드와 동일합니다. 앱은 이 형식으로 파싱합니다.

```json
{ "success": true, "message": "...", "data": { }, "errorCode": null }
```

에러 코드는 `VALIDATION_ERROR`, `UNAUTHORIZED`처럼 대문자와 밑줄로 쓴 문자열 상수입니다. 예약 실패 등은 `errorCode`를 화면 문구에 매핑합니다.

API Base URL: `http://localhost:8080/api/v1`  
Swagger UI: `http://localhost:8080/swagger-ui/index.html`
